RDFa Editor - Boundary-Respecting Annotation

Instructions

Right-click a text selection in the editable sections below to annotate it with RDFa. Right-click an existing annotation to edit or remove it. Plain clicks stay free for text editing.

Note: Selections must respect HTML element boundaries. Select either:

  • Text within an element (e.g., just "John Doe" inside the <strong> tags)
  • An entire element (e.g., the whole "<strong>John Doe</strong>")

Visual Feedback:

  • ✅ Valid selection → Annotation popup appears
  • ❌ Invalid selection (crosses element boundaries) → Selection flashes red, no popup

Test Case 1: Plain Text (Always Works)

This is plain text with no formatting. You can select any portion of this text and it will work perfectly.

Test Case 2: Bold and Italic Text

Our company was founded by Dr. Jane Smith in 2020. She graduated from MIT and now leads our innovation team.

✅ Try: Select "Dr. Jane Smith" (text inside <strong>)
✅ Try: Select "MIT" (text inside <em>)
❌ Try: Select "founded by Dr. Jane Smith" (crosses <strong> boundary - will shake)

Test Case 3: Links

Visit our official website or check out our blog for more information.

✅ Try: Select "official website" (text inside <a>)
✅ Try: Select "our blog" (text inside <a>)
❌ Try: Select "our official website" (crosses <a> boundary - will shake)

Test Case 4: Nested Formatting

Contact Dr. Alice Johnson at the research@example.com email address.

✅ Try: Select "Dr. Alice Johnson" (text inside nested <em><strong>)
✅ Try: Select "research@example.com" (text inside <code>)
❌ Try: Select "Contact Dr. Alice" (crosses <em> boundary - will shake)

Test Case 5: Mixed Content (Complex)

CEO Jane Smith announced that ACME Corporation will launch a new product in Q4 2024.

✅ Try: Select "CEO" (inside <strong>)
✅ Try: Select "Jane Smith" (inside <em>)
✅ Try: Select "ACME Corporation" (inside <a>)
❌ Try: Select "CEO Jane Smith" (crosses multiple elements - will shake)
❌ Try: Select "Jane Smith announced" (crosses <em> boundary - will shake)
