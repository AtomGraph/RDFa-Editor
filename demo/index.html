LinkedDataHub blocks in the editor

This page runs the editor with the LinkedDataHub blocks extension: blocks defined purely in RDF — queries, charts, referenced resources — embedded wherever an ordinary XHTML block can go. Each one is stored as a few RDFa attributes; the rendering below is fetched and drawn on the fly (content-negotiated from this server) and is never saved with the page. Check Source in the toolbar to see the storage form, or Extract RDF for the triples.

Try it: press / in an empty paragraph and pick "Block…", or use the ▦ toolbar button. Select a block with the arrow keys, delete it with Backspace, undo with Ctrl/Cmd+Z — it behaves as one atomic unit.
